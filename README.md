# Ашиглалтын зардал хуваарилах

Цахилгаан, дулаан, усны сарын зардлыг тооцож, төрлөөр нь нэгтгэн харах дотоод веб апп.

## Боломжууд

- Монгол хэл дээрх responsive React + TypeScript + Vite интерфейс
- Цахилгаан, дулаан, усны зардал бүртгэх
- Тоолуурын заалт ашиглах эсвэл нэхэмжлэлийн нийт дүнг шууд оруулах
- Хэрэглээ, үндсэн дүн, НӨАТ, нэмэлт төлбөр, нийт дүнг автоматаар бодох
- Квц коэффициент оруулж, хэрэглээг `(Сүүлийн заалт - Эхний заалт) x Квц` томьёогоор бодох
- Нэг зардлын форм дотор хэд хэдэн заалтын мөр нэмж, мөрүүдийн нийлбэрийг харах
- Зүүн талын самбарт зардлыг төрлөөр нь, нийт дүн ба эзлэх хувийн хамт харах
- Тайлант сараар болон зардлын төрлөөр шүүх
- Өгөгдлийг browser-ийн LocalStorage-д автоматаар хадгалах
- XLSX импортлох, тооцоолсон үр дүнг XLSX-ээр татах
- Excel бөглөх загвар болон зааврын хуудас татах

## Ажиллуулах

Шаардлага: Node.js 18+.

```bash
npm install
npm run dev
```

Дараах хаягаар нээнэ:

```text
http://localhost:5173
```

Бусад шалгалт:

```bash
npm run typecheck
npm test
npm run build
```

## Тооцоолол

Заалтаар тооцох үед:

- Хэрэглээ = (Сүүлийн заалт - Эхний заалт) x Квц
- Үндсэн дүн = Хэрэглээ x Нэгж үнэ
- НӨАТ = Үндсэн дүн x НӨАТ хувь / 100
- Нийт дүн = Үндсэн дүн + НӨАТ + Нэмэлт төлбөр

Нэхэмжлэлийн нийт дүнгээр оруулах үед үндсэн дүн нь хэрэглэгчийн оруулсан нэхэмжлэлийн дүн байна. НӨАТ болон нэмэлт төлбөр нь сонголттой.

## Excel

`Загвар татах` товчоор жишээ мөр, баганын тайлбар бүхий XLSX файл татна. Үндсэн хуудсын дараах талбаруудыг бөглөж импортлоно:

- `Төрөл`: Цахилгаан, Дулаан, эсвэл Ус
- `Тайлант сар`: `YYYY-MM`, жишээ нь `2026-08`
- `Нэр/Тайлбар` (заавал биш)
- `Тооцох арга`: `Заалтаар тооцох` эсвэл `Нийт дүнгээр оруулах`
- Заалтын арга бол эхний заалт, сүүлийн заалт, нэгж үнэ
- Шууд дүнгийн арга бол нэхэмжлэлийн дүн
- НӨАТ (%) болон нэмэлт төлбөрийг шаардлагатай бол бөглөнө

Хэрэглээ, үндсэн дүн, НӨАТ-ын дүн, нийт дүнгийн багануудыг импортлох үед систем дахин бодно.

## Өгөгдөл

Өгөгдөл бүхэлдээ browser-ийн LocalStorage-д хадгалагдана — сервер байхгүй.
Түлхүүрүүд нь `azh.` болон `zardal.` угтвартай:

| Түлхүүр | Агуулга |
| --- | --- |
| `azh.bills.v1` | Нэхэмжлэлийн бүртгэл |
| `azh.accountReconciliation.v2` | Дансны тулгалт |
| `azh.allocation-bases.v1` | Хуваарилалтын суурь |
| `azh.departments.v1` | Алба нэгж |
| `azh.products.v1` | Бүтээгдэхүүн |
| `zardal.electricity.baseInput.v1` | 1-р алхмын суурь өгөгдөл |
| `zardal.electricity.orgUnits.v1` | Байгууллагын нэгжүүд |
| `zardal.electricity.productInfo.v1` | Бүтээгдэхүүний мэдээлэл |
| `zardal.electricity.journal.<сар>.v1` | Журналын бичилт (сар тус бүрд) |
| `zardal.electricity.step2.<сар>.v1*` | 2-р алхмын хуваарилалт (сар, үйлдвэр тус бүрд) |

### Анхаарах

LocalStorage нь **origin бүрд тусдаа** байдаг. `http://localhost:5173` болон
deploy хийсэн хаяг нь тус тусдаа өгөгдөлтэй — хооронд нь автоматаар
шилжихгүй. Мөн browser-ийн site data цэвэрлэх, өөр browser/компьютер
ашиглах үед өгөгдөл алга болно. Хэрэглэгч бүр өөрийн өгөгдөлтэй байх тул
хамт олон хооронд хуваалцагдахгүй.

### Нөөцлөх ба зөөх

`tools/localstorage-export.js` болон `tools/localstorage-import.js` нь
дээрх бүх түлхүүрийг (динамикаар үүсдэг сар/үйлдвэрийн түлхүүрүүдийг
оруулаад) JSON файлаар зөөнө.

1. Эх хаягаа browser-т нээгээд DevTools console нээнэ (F12).
2. `tools/localstorage-export.js`-ийн агуулгыг наан ажиллуулна — JSON
   файл татагдана.
3. Зорилтот хаягаа нээж, console-д `tools/localstorage-import.js`-ийг
   наан ажиллуулж, татсан файлаа сонгоно. Давхардсан түлхүүр байвал
   дарж бичихийн өмнө асууна.

> Chrome console эхний удаа наахыг хориглодог. Хориглосон бол console-д
> `allow pasting` гэж бичээд Enter дарна.

Excel экспорт нь зөвхөн нэхэмжлэлийн хэсгийг хамардаг тул бүрэн нөөцлөлт
болохгүй — дээрх script-ийг ашиглана.

## Хүрээ

Энэ хувилбар нь нэхэмжлэлийн зардлыг тооцох 1-р үе шат юм. Цех/алба бүрт, дараа нь бүтээгдэхүүн бүрт олон төрлийн сууриар хуваарилах workflow нь дараагийн үе шатанд нэмэгдэхээр тусгаарлагдсан. Одоогийн хувилбарын зүүн самбар нь цахилгаан, дулаан, усны зардлыг төрлөөр нэгтгэн харуулна.
